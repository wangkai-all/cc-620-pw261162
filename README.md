# 岗位课程推荐 · 时间切分对照台

一个完全本地、零外部依赖（仅 Node.js 内置模块）的教学样例：用虚构的员工岗位与课程完成事件，
演示推荐系统离线评估中**点时间（point-in-time）纪律**——候选生成与特征构造只能使用决策时刻 T
当时可见的目录与历史事件，不能用未来事件补旧特征。

## 启动

```bash
node server.js          # 在 src/ 目录外可用：npm start
# 或指定端口（PORT 由环境变量读取，默认 3000，始终绑定 127.0.0.1）
PORT=8080 node src/server.js
```

打开 <http://127.0.0.1:3000/>，在同一次会话里依次点击：

1. **重放原推荐规则** —— 基线目录 C1~C8（T 前全部开放），同时给出正确/错误两种切分
2. **新增后开放课程** —— 加入 C9（2026-05-18 开放，晚于 T=2026-04-01）
3. **查看候选与评估差异** —— 逐员工候选对照、指标对照、C9 分桶、点时间不变量核对

页面所有业务结果区都带 `data-evidence-result` 属性（如 `replay`、`add-late-course`、`diff`、
`diff-candidates`、`diff-buckets`、`diff-invariants` 等），便于自动化核对操作前后内容。

## 测试

```bash
npm test                # 等价于 node --test "test/**/*.test.js"
```

28 个用例覆盖正常与异常路径：虚构数据确定性、点时间候选纪律、冷启动与空候选、未知员工、
分桶守恒、除零保护、状态机非法顺序（409）、未知操作/非法 JSON（400）、路径穿越（404）等。

## 数据与时间线（全部虚构、固定种子可复现）

| 时间点 | 含义 |
| --- | --- |
| 2026-01 ~ 2026-03 | C1~C8 陆续开放，员工产生历史完成事件 |
| **T = 2026-04-01** | 候选生成 / 特征截断时刻 |
| 2026-05-18 | **C9 才开放**（晚于 T，属于“后来才开放的课程”） |
| 2026-07-01 | 评估窗口结束；标签只取 `[T, 结束)` 内的完成事件 |

- 12 名员工，4 个岗位（销售/工程师/市场/人力），54 条确定性生成的完成事件
- E04：T 前完成全部可见课程 → 正确候选为空（可见的都学完了）
- E12：T 前零完成事件 → 冷启动，仅靠岗位共性出候选

## 推荐规则

候选 = T 时可见目录中本人尚未完成的课程，按下列加权分排序取 Top 5：

- **岗位共性（权重 0.6）**：同岗位员工对该课程的完成人数占比
- **相近历史（权重 0.4）**：本人已完成课程与该课程完成者集合的 Jaccard 相似度

## 正确切分 vs 错误切分

| 环节 | 正确切分 | 错误切分（演示用反例） |
| --- | --- | --- |
| 候选目录 | 只含 T 时已开放课程 | 把 T 之后才开放的 C9 也放进候选（**未来目录泄漏**） |
| 岗位统计特征 | 只用 T 前完成事件 | 混入窗口内未来完成事件（**用未来补旧特征**） |
| 评估标签 | 只用 `[T, 结束)` 的完成事件 | 同左（标签窗口本身一致，差异在候选与特征） |

## 评价分桶：看不到 ≠ 看到了但没完成

对扩展目录下的每门课程、每名员工严格分桶，两类负向情况互不污染：

- `NOT_VISIBLE`：T 时课程未开放，员工**根本看不到**（C9 对 5 名员工落入此桶）
- `INVISIBLE_LABEL_ONLY`：T 时看不到，但课程开放后员工完成了它（C9 对 7 名员工落入此桶）
- `VISIBLE_NOT_DONE`：T 时已开放、**看得到但没完成**
- `HIT / WASTED / MISSED`：可见课程上的命中、浪费推荐、漏召
- `INVISIBLE_HIT`：错误流水线推荐了未开放课程且员工后来完成——正确口径**拒绝**把它计为命中

## 典型指标影响（本样例实际数值，测试中固化为不变量）

- 基线目录：错误切分因未来事件进岗位统计，召回被抬高到 100%（正确为 90.0%），精确率 20.4% vs 18.4%
- 扩展目录：错误切分 15.1% 的推荐指向员工在 T 时看不到的 C9（8 条不可见推荐、6 条 INVISIBLE_HIT），
  可见召回反被 C9 挤出 Top5 而降到 90%；若把 INVISIBLE_HIT 也算命中，精确率会虚高到 28.3%
  （正确口径精确率只有 18.4% 且拒绝承认这类命中）
- 正确切分在新增 C9 前后**候选与可见指标完全不变**（12/12 员工候选一致）——这正是点时间纪律应有的表现

```

src/evaluation.js  标签窗口与八类评价分桶、指标
src/scenarios.js   基线/扩展 × 正确/错误四条流水线与不变量

test/              node:test 用例
```
